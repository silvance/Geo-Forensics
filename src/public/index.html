Support & Information

Working with forensic exports (Magnet AXIOM & others)

GeoForensics analyzes the metadata embedded in the files you supply. When exporting evidence from a forensic suite such as Magnet AXIOM, export the original / native file whenever possible. Location information that exists only in a separate case artifact or database — not inside the media file itself — cannot be recovered by GeoForensics from an exported image that does not contain that metadata. GeoForensics does not parse AXIOM case files; it reads the exported originals.

Timestamps & timezones

Many EXIF timestamps carry no timezone. GeoForensics never assumes UTC or your system time: such timestamps are shown as a local wall-clock of unknown timezone (marked ⚠), while timestamps with a genuine embedded offset show it (e.g. UTC+02:00). The timeline is ordered by wall-clock value, deterministically. The field used (DateTimeOriginal / CreateDate / ModifyDate) and all raw values are preserved in exports.

Offline / air-gapped use

With Air-Gapped Mode on (the default), no data leaves the workstation: no update checks, no online map tiles, no outbound requests of any kind. Import a local MBTiles map package in Settings to show evidence on a basemap without a connection. Every file gets a SHA-256, and the Case Report / Forensic Manifest record full scan provenance.

Settings

Air-Gapped Mode

On by default and recommended for forensic workstations. Blocks all outbound network requests — update checks, GitHub, and every online map tile server. Only the local map server and imported offline maps are used. Turn this off deliberately if you need online basemaps or updates on a connected machine.

Offline Maps

No offline map imported.

Import a raster MBTiles map package to display evidence on a fully offline basemap. The file is read from where it lives — it is not copied — so keep it on the workstation. Evidence points outside the map's coverage are flagged.

Updates

Off by default. Automatically check for new releases on GitHub and prompt before downloading. Has no effect while Air-Gapped Mode is on — update checks stay fully suppressed.

Appearance

Optimizes visibility for bright environments and direct sunlight.

Performance & Media

Displays thumbnails in the map and sidebar. Note: May throttle performance during large bulk operations.

Timeline Reconstruction & Tracking

Traces the chronological movement between evidence points. Direction cones show which way the camera was facing (when the photo recorded it).
